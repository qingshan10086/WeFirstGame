# 可破碎砖块 (BreakableBrick)

一个Unity 2D平台游戏中的可破碎砖块脚本，当玩家踩上去后经过指定时间会自动破碎，破碎后经过一段时间又会自动复原。

## 功能特点

1. **玩家检测**：通过标签自动识别玩家
2. **延迟破碎**：可配置踩上去到破碎的延迟时间
3. **不可取消的破碎过程**：一旦触发破碎倒计时，即使玩家离开砖块，破碎过程仍会继续执行
4. **自动复原**：破碎后经过指定时间自动复原
5. **完整的动画支持**：破碎和复原动画均可完整播放到最后一帧
6. **动画事件支持**：完全通过动画事件函数控制动画的播放和结束
7. **无动画长度依赖**：不再依赖动画剪辑长度，完全由动画事件决定动画结束时机
8. **破碎效果**：支持动画、粒子效果和音效
9. **复原效果**：支持动画和音效
10. **调试支持**：包含调试信息和可视化辅助

## 配置参数

| 参数名称 | 类型 | 默认值 | 说明 |
|---------|------|-------|------|
| breakDelay | float | 1.5f | 玩家踩上去到破碎的延迟时间（秒） |
| respawnDelay | float | 5.0f | 破碎后到复原的延迟时间（秒） |
| showDebugInfo | bool | false | 是否显示调试信息 |
| animator | Animator | null | 动画组件（用于播放破碎和复原动画） |
| breakBoolName | string | "Break" | 破碎动画的Bool参数名称 |
| respawnBoolName | string | "Respawn" | 复原动画的Bool参数名称 |
| breakParticles | ParticleSystem | null | 破碎粒子效果 |
| breakAudio | AudioSource | null | 破碎音效 |
| respawnAudio | AudioSource | null | 复原音效 |

## 使用方法

### 基本使用

1. 创建一个砖块游戏对象（SpriteRenderer + Collider2D）
2. 将 `BreakableBrick.cs` 脚本挂载到砖块对象上
3. 将 `BreakableBrickAnimationEvent.cs` 脚本挂载到同一个砖块对象上（或动画所在的子对象上）
4. 确保玩家对象的标签设置为 "Player"
5. 调整 `breakDelay` 参数设置破碎延迟时间
6. 调整 `respawnDelay` 参数设置复原延迟时间

### 添加破碎和复原效果

1. **动画效果**：
   - 为砖块添加 Animator 组件
   - 创建包含破碎和复原动画的 Animator Controller
   - 在 Animator Controller 中添加名为 `Break` 和 `Respawn` 的布尔参数
   - 设置从Idle到破碎动画的过渡条件：`Break=true`
   - 设置从破碎动画到复原动画的过渡条件：`Break=false && Respawn=true`
   - 设置从复原动画到Idle的过渡条件：`Respawn=false`
   - 确保动画循环模式正确设置
   - 将 Animator 引用拖放到脚本的 `animator` 字段
   - 设置 `breakBoolName` 为破碎动画的Bool参数名称（默认："Break"）
   - 设置 `respawnBoolName` 为复原动画的Bool参数名称（默认："Respawn"）

2. **配置动画事件**：在动画编辑器中添加以下事件：
   - 在**破碎动画**的关键时间点（如开始破碎时）添加事件：`OnAnimationKeyEvent("break_effect")`
   - 在**复原动画**的最后一帧添加事件：`OnRespawnAnimationComplete()`

3. **粒子效果**：
   - 创建或导入破碎粒子效果
   - 将粒子系统作为子对象添加到砖块上
   - 将粒子系统引用拖放到脚本的 `breakParticles` 字段

4. **音效**：
   - 添加 AudioSource 组件到砖块上用于破碎音效
   - 将破碎音效设置好并拖放到脚本的 `breakAudio` 字段
   - 添加 AudioSource 组件到砖块上用于复原音效（可选）
   - 将复原音效设置好并拖放到脚本的 `respawnAudio` 字段

## 注意事项

1. **碰撞器设置**：确保砖块的 Collider2D 是实体碰撞体（`isTrigger` = false）
2. **玩家标签**：玩家对象必须设置标签为 "Player"，否则不会触发破碎
3. **物理材质**：可以给砖块添加物理材质，增加玩家在上面的摩擦力
4. **图层设置**：建议将砖块放在单独的图层（如 "Environment"），方便管理
5. **性能优化**：
   - 禁用不需要的效果（如粒子或音效）可以提高性能
   - 大量使用时建议使用对象池

## 工作流程

1. 玩家踩上砖块 → 触发 `OnCollisionEnter2D`
2. 脚本检测玩家标签 → 开始破碎倒计时协程（一旦触发，即使玩家离开砖块，倒计时仍会继续执行）
3. 倒计时结束 → 执行破碎效果
4. 播放动画、粒子和音效 → 禁用碰撞器
5. 等待效果完成 → 开始复原倒计时协程
6. 复原倒计时结束 → 执行复原装效果
7. 播放动画和音效 → 重新启用碰撞器
8. 砖块恢复可用状态

## 扩展建议

1. **重新生成功能**：添加定时重新生成砖块的功能
2. **多段破碎**：实现砖块分阶段破碎的效果
3. **掉落物品**：破碎时随机掉落物品
4. **力反馈**：破碎时给玩家施加向上的力，模拟砖块破碎的反弹效果
5. **耐久度系统**：实现需要多次踩踏才会破碎的砖块

## 调试

- 开启 `showDebugInfo` 可以在场景视图中看到砖块的状态信息
- 控制台会输出玩家踩踏和破碎的相关信息
- Gizmos 会显示砖块的碰撞器范围
