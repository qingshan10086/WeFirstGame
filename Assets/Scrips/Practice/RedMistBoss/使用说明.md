# Boss战系统使用说明

## 1. 系统概述

Boss战系统是一个模块化的事件驱动系统，用于管理游戏中的Boss战场景，包括UI显示、音乐切换、相机控制等功能。系统采用事件订阅模式，各组件之间松耦合，便于扩展和维护。

## 2. 核心文件说明

| 文件名 | 功能说明 |
|--------|----------|
| `EventManager.cs` | 事件管理核心，负责发布和订阅Boss战相关事件 |
| `BossBattleTrigger.cs` | Boss战触发组件，检测玩家进入Boss战区域 |
| `BossBattleUI.cs` | Boss战UI管理，包括警告面板、生命值条和两阶段画布显示 |
| `BossBattleMusicManager.cs` | Boss战音乐管理，支持两阶段音乐切换 |
| `BossBattleCameraController.cs` | Boss战相机控制，使用Cinemachine虚拟相机 |

## 3. 使用步骤

### 3.1 基础设置

1. **创建EventManager**
   - 在场景中创建一个空对象，命名为"EventManager"
   - 挂载`EventManager`脚本到该对象上
   - 该对象会自动设置为`DontDestroyOnLoad`，在场景切换时保持存在

2. **创建Boss战触发器**
   - 在Boss战入口处创建一个空对象，命名为"BossBattleTrigger"
   - 添加`BoxCollider2D`组件，并勾选"Is Trigger"
   - 调整碰撞体大小覆盖Boss战触发区域
   - 挂载`BossBattleTrigger`脚本

3. **配置Boss战UI**
   - 创建UI画布，命名为"BossBattleUI"
   - 挂载`BossBattleUI`脚本
   - 在Inspector中设置以下UI元素：
     - Boss战斗面板 (`bossBattleUIPanel`)
     - Boss生命值条 (`bossHealthBar`)
     - Boss名称文本 (`bossNameText`)
     - 倒计时文本 (`countdownText`)
     - Boss警告面板 (`bossWarningPanel`)
     - 第二阶段画布1 (`phase2Canvas1`) - 用于过渡动画
     - 第二阶段画布2 (`phase2Canvas2`) - 作为Boss战背景

### 3.2 配置音乐系统

1. **创建音乐管理器**
   - 创建空对象，命名为"BossBattleMusicManager"
   - 挂载`BossBattleMusicManager`脚本
   - 在Inspector中设置以下参数：
     - `normalMusicSource` - 普通场景音乐源
     - `bossMusicSource` - Boss战第一阶段音乐源
     - `bossMusicPhase2Source` - Boss战第二阶段音乐源
     - `fadeDuration` - 音乐淡入淡出时长
     - `normalMusicVolume` - 普通音乐音量
     - `bossMusicVolume` - Boss战第一阶段音乐音量
     - `bossMusicPhase2Volume` - Boss战第二阶段音乐音量

### 3.3 配置相机系统

1. **创建相机控制器**
   - 创建空对象，命名为"BossBattleCameraController"
   - 挂载`BossBattleCameraController`脚本
   - 在Inspector中设置：
     - `playerVirtualCamera` - 玩家跟随相机
     - `bossVirtualCamera` - Boss战专用相机
     - `bossCameraPosition` - Boss战相机固定位置

## 4. 配置参数说明

### 4.1 EventManager参数

无需额外配置，脚本会自动初始化。

### 4.2 BossBattleUI参数

| 参数名称 | 类型 | 说明 |
|----------|------|------|
| `bossName` | String | Boss名称，显示在UI上 |
| `warningDuration` | Float | 警告面板显示时长 |
| `fadeDuration` | Float | UI淡入淡出时长 |
| `phaseTransitionDuration` | Float | 两阶段画布之间的过渡时间 |

### 4.3 BossBattleMusicManager参数

| 参数名称 | 类型 | 说明 |
|----------|------|------|
| `fadeDuration` | Float | 音乐淡入淡出时长 |
| `normalMusicVolume` | Float | 普通场景音乐音量 (0-1) |
| `bossMusicVolume` | Float | Boss战第一阶段音乐音量 (0-1) |
| `bossMusicPhase2Volume` | Float | Boss战第二阶段音乐音量 (0-1) |

### 4.4 BossBattleCameraController参数

| 参数名称 | 类型 | 说明 |
|----------|------|------|
| `bossCameraPosition` | Transform | Boss战相机固定位置 |

## 5. 事件系统说明

### 5.1 核心事件

| 事件名称 | 触发时机 |
|----------|----------|
| `OnBossBattleStart` | Boss战开始时 |
| `OnBossBattleSecondPhase` | Boss战第二阶段开始时 |
| `OnBossBattleEnd` | Boss战结束时 |
| `OnBossDefeated` | Boss被击败时 |

### 5.2 触发事件方法

在脚本中调用以下方法可以触发对应事件：

```csharp
// 触发Boss战开始
EventManager.Instance.TriggerBossBattleStart();

// 触发Boss战第二阶段
EventManager.Instance.TriggerBossBattleSecondPhase();

// 触发Boss战结束
EventManager.Instance.TriggerBossBattleEnd();

// 触发Boss被击败
EventManager.Instance.TriggerBossDefeated();
```

### 5.3 订阅事件示例

在需要响应Boss战事件的脚本中，使用以下方式订阅事件：

```csharp
private void OnEnable()
{
    EventManager.Instance.OnBossBattleStart.AddListener(OnBossBattleStarted);
    EventManager.Instance.OnBossBattleEnd.AddListener(OnBossBattleEnded);
}

private void OnDisable()
{
    EventManager.Instance.OnBossBattleStart.RemoveListener(OnBossBattleStarted);
    EventManager.Instance.OnBossBattleEnd.RemoveListener(OnBossBattleEnded);
}

private void OnBossBattleStarted()
{
    // Boss战开始时执行的逻辑
}

private void OnBossBattleEnded()
{
    // Boss战结束时执行的逻辑
}
```

## 6. Boss战流程说明

1. **玩家进入触发区域** → `BossBattleTrigger`检测到玩家
2. **触发Boss战开始事件** → `EventManager.TriggerBossBattleStart()`
3. **UI显示流程**：
   - 显示Boss警告面板
   - 显示3秒倒计时
   - 显示Boss战主UI面板
   - 显示第一阶段画布（有淡入淡出效果）
   - 显示第二阶段画布（作为背景，无需淡入）
   - 触发第二阶段事件
4. **音乐切换**：
   - 从普通音乐淡入Boss战第一阶段音乐
   - 第二阶段触发时，从第一阶段音乐淡入第二阶段音乐
5. **相机切换**：
   - 切换到Boss战专用相机
   - 相机位置固定在`bossCameraPosition`
6. **Boss战结束** → 触发`OnBossBattleEnd`事件
   - 隐藏所有Boss战UI
   - 切换回普通音乐
   - 恢复玩家跟随相机

## 7. 常见问题和解决方案

### 7.1 事件不触发
- 检查`EventManager`是否在场景中存在
- 检查事件订阅是否正确，确保在`OnEnable`中订阅，在`OnDisable`中取消订阅
- 检查事件触发方法是否被正确调用

### 7.2 UI显示异常
- 检查UI元素是否正确引用
- 检查Canvas的Render Mode是否设置正确
- 检查CanvasGroup组件是否存在且配置正确

### 7.3 音乐切换不顺畅
- 检查音频源是否正确设置
- 调整`fadeDuration`参数，增加过渡时间
- 确保音频文件已正确导入且格式支持

### 7.4 相机控制问题
- 检查Cinemachine虚拟相机是否正确配置
- 确保`bossCameraPosition`已正确设置
- 检查相机优先级设置

## 8. 扩展建议
