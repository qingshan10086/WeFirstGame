# 攻击范围实现说明

## 实现概述

已为TomMali敌人的三个技能实现了独立的攻击范围和检测逻辑：

1. **技能1**：黑色圆形攻击范围
2. **技能2**：红色圆形攻击范围  
3. **技能3**：蓝色圆形攻击范围

## 技术实现

### 1. 攻击范围变量定义

在`TomMali.cs`中定义了以下攻击范围相关变量：

```csharp
[Header("技能攻击范围")]
// 技能1攻击范围 - 黑色圆形
[SerializeField] protected Transform skill1Attack;
[SerializeField] protected float skill1AttackRange = 2f;  // 技能1攻击半径

// 技能2攻击范围 - 红色圆形
[SerializeField] protected Transform skill2Attack;
[SerializeField] protected float skill2AttackRange = 3f;  // 技能2攻击半径

// 技能3攻击范围 - 蓝色圆形
[SerializeField] protected Transform skill3Attack;
[SerializeField] protected float skill3AttackRange = 2.5f;  // 技能3攻击半径
```

### 2. 攻击检测方法

为每个技能实现了独立的攻击检测方法：

- **CheckSkill1Attack()**：技能1攻击检测
- **CheckSkill2Attack()**：技能2攻击检测  
- **CheckSkill3Attack()**：技能3攻击检测

所有检测方法都使用`Physics2D.OverlapCircleAll`实现，检测指定范围内的玩家碰撞体。

### 3. 检测时机

- **技能1**：在冲刺过程中持续检测
- **技能2**：在准备攻击时检测
- **技能3**：在跳跃落地时检测

### 4. 可视化绘制

在`OnDrawGizmos()`方法中实现了攻击范围的可视化：

- 黑色圆形：技能1攻击范围
- 红色圆形：技能2攻击范围
- 蓝色圆形：技能3攻击范围

## Unity编辑器设置

在Unity编辑器中，需要为TomMali敌人对象设置以下内容：

1. 创建三个子物体作为攻击检测点：
   - `skill1Attack`：技能1攻击检测点
   - `skill2Attack`：技能2攻击检测点
   - `skill3Attack`：技能3攻击检测点

2. 将这些子物体拖拽到Inspector面板中对应的字段：
   - `Skill Attack Range`部分下的`skill1Attack`字段
   - `Skill Attack Range`部分下的`skill2Attack`字段  
   - `Skill Attack Range`部分下的`skill3Attack`字段

3. 根据需要调整各技能的攻击范围半径。

## 攻击效果

当玩家进入技能攻击范围时，控制台会输出相应的日志信息：
- 技能1："技能1攻击到玩家"
- 技能2："技能2攻击到玩家"
- 技能3："技能3攻击到玩家"

可以在各检测方法的注释位置添加具体的伤害逻辑或其他攻击效果。

## 注意事项

1. 确保攻击检测点的位置设置合理，通常应位于敌人攻击的前端或中心位置。
2. 攻击范围半径可以根据游戏平衡需要进行调整。
3. 攻击检测逻辑目前仅输出日志，需要添加实际的伤害或效果处理代码。
