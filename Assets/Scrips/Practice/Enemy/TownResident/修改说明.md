# 技能一修改说明

## 修改内容

1. **添加状态标记变量**：
   - 在技能执行状态部分添加了 `skillOneDirectionSet` 布尔变量，用于标记技能一是否已经确定朝向。

2. **修改技能一执行逻辑**：
   - 将玩家朝向检测逻辑移到 `if (!skillOneDirectionSet)` 条件块中，确保只有在技能一开始时才会确定朝向。
   - 确定朝向后，设置 `skillOneDirectionSet = true` 标记朝向已确定。
   - 之后保持该朝向不变，直到撞到墙或技能结束。

3. **重置状态标记**：
   - 在 `EndSkill` 方法中重置 `skillOneDirectionSet = false`，确保下次使用技能一时能重新确定朝向。

## 实现效果

当敌人执行技能一时：
1. 技能开始时会检测玩家位置，并优先面向玩家确定初始朝向。
2. 确定朝向后，敌人会保持该朝向不变，向指定方向冲刺。
3. 冲刺过程中，即使玩家移动，敌人也不会改变朝向。
4. 只有当敌人撞到墙或技能结束时，才会停止冲刺并重置状态。

## 测试建议

1. 让玩家站在敌人左侧，触发敌人技能一，观察敌人是否向右冲刺且过程中不改变朝向。
2. 让玩家站在敌人右侧，触发敌人技能一，观察敌人是否向左冲刺且过程中不改变朝向。
3. 确保敌人冲刺时撞到墙会正确结束技能。
