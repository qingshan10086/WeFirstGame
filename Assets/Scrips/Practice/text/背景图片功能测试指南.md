# 背景图片功能测试指南

## 测试概述

本文档提供文本触发系统背景图片功能的测试步骤，确保背景图片能正确显示、动画和与背景颜色协同工作。

## 测试准备

### 1. 资源准备

- 准备1-2张用于文本背景的Sprite图片（建议使用透明背景的PNG格式）
- 将图片放入`Resources/TextBackgrounds/`文件夹（如果没有该文件夹，请创建）

### 2. 场景设置

1. 确保场景中已经配置了TextDisplayManager：
   - 包含Text组件的UI元素
   - 包含Image组件的Panel

2. 创建一个简单的测试场景：
   - 添加一个Player对象（带Collider2D和Rigidbody2D）
   - 设置Player标签为"Player"

## 测试步骤

### 测试1：直接代码调用测试

1. 创建一个测试脚本`TextBackgroundTest.cs`：

```csharp
using UnityEngine;
using System.Collections;

public class TextBackgroundTest : MonoBehaviour
{
    private Sprite talkBubble;
    private Sprite signBoard;

    void Start()
    {
        // 加载测试背景图片
        talkBubble = Resources.Load<Sprite>("TextBackgrounds/TalkBubble");
        signBoard = Resources.Load<Sprite>("TextBackgrounds/SignBoard");
    }

    [ContextMenu("Test Background Image")]
    public void TestBackgroundImage()
    {
        // 测试1：带背景图片的文本
        TextDisplayManager.Instance.DisplayText(
            "这是带对话气泡的文本", 
            3f, 
            Color.black, 
            Color.clear, 
            talkBubble, 
            true
        );
    }

    [ContextMenu("Test Background Image with Color")]
    public void TestBackgroundImageWithColor()
    {
        // 测试2：背景图片+半透明背景色
        TextDisplayManager.Instance.DisplayText(
            "带背景图片和颜色的文本", 
            3f, 
            Color.white, 
            new Color(0, 0, 0, 0.3f), 
            signBoard, 
            true
        );
    }

    [ContextMenu("Test Multiple Backgrounds")]
    public void TestMultipleBackgrounds()
    {
        // 测试3：多个带不同背景的文本队列
        TextDisplayManager.Instance.DisplayText("普通文本（无背景）", 2f);
        
        TextDisplayManager.Instance.DisplayText(
            "对话气泡文本", 
            2f, 
            Color.black, 
            Color.clear, 
            talkBubble, 
            true
        );
        
        TextDisplayManager.Instance.DisplayText(
            "招牌文本", 
            2f, 
            Color.white, 
            new Color(0, 0, 0, 0.3f), 
            signBoard, 
            true
        );
    }

    [ContextMenu("Test Background Position and Size")]
    public void TestBackgroundPositionAndSize()
    {
        // 测试4：背景图片位置偏移和大小缩放
        Vector2 positionOffset = new Vector2(30f, 20f); // 向右上方偏移
        Vector2 sizeScale = new Vector2(1.5f, 1.2f); // 宽度放大1.5倍，高度放大1.2倍
        
        TextDisplayManager.Instance.DisplayText(
            "带自定义位置和大小的背景", 
            4f, 
            Color.black, 
            Color.clear, 
            talkBubble, 
            true,
            positionOffset,
            sizeScale
        );
    }
}
```

2. 将脚本添加到任意游戏对象上
3. 在Inspector中右键点击脚本组件，选择测试方法：
   - `Test Background Image`：测试基本背景图片显示
   - `Test Background Image with Color`：测试背景图片+背景颜色
   - `Test Multiple Backgrounds`：测试多个带背景的文本队列

### 测试2：TextData测试

1. 创建一个TextData对象：
   - 右键点击Project窗口，选择`Create > Game Data > Text Data`
   - 命名为`BackgroundImageTest`

2. 配置TextData：
   - `displayText`："TextData配置的带背景图片的文本"
   - `backgroundColor`：半透明黑色（0,0,0,0.3）
   - `backgroundImage`：选择一张测试Sprite
   - `useBackgroundImage`：勾选

3. 创建TextTriggerZone：
   - 创建空对象，添加`TextTriggerZone`组件
   - 设置`triggerWidth`和`triggerHeight`为合适大小
   - 勾选`useTextData`，并分配创建的`BackgroundImageTest`
   - 设置`playerTag`为"Player"

4. 运行游戏，控制Player进入触发区域，检查文本是否正确显示

### 测试3：多个文本背景切换测试

1. 创建2-3个不同的TextData对象：
   - 为每个TextData设置不同的`displayText`
   - 为每个TextData分配不同的`backgroundImage`
   - 确保`useBackgroundImage`都已勾选

2. 创建多个TextTriggerZone或使用代码连续调用：
   - 确保`displayImmediately`设置为false，以便文本按队列顺序显示
   - 测试不同背景图片的平滑切换效果

3. 验证每个文本都正确显示其对应的背景图片

## 预期结果

1. **基本功能**：
   - 带背景图片的文本应正确显示
   - 背景图片应保持比例并适配文本面板
   - 淡入淡出动画应同时应用于文本和背景图片

2. **背景颜色协同**：
   - 背景图片和背景颜色应能同时显示
   - 透明度应正确叠加

3. **文本队列**：
   - 带不同背景的文本应按顺序显示
   - 切换时背景图片应正确更新

4. **多个文本切换**：
   - 不同文本之间的背景图片应正确切换
   - 队列中的文本应按顺序显示各自的背景
   - 切换过程应平滑无闪烁

## 常见问题排查

### 问题1：背景图片不显示

- 检查`useBackgroundImage`是否勾选
- 确认Sprite资源已正确加载
- 检查TextPanel的Image组件是否正确配置

### 问题2：背景图片变形

- 确保`backgroundSpriteImage.type`设置为`Image.Type.Simple`
- 检查`preserveAspect`是否设置为`true`

### 问题3：背景颜色不显示

- 确保背景图片的透明度设置正确
- 检查背景图片是否覆盖了整个面板

## 测试完成

如果所有测试都通过，说明背景图片功能已正常工作。您可以在实际游戏中使用该功能创建丰富的文本显示效果！
